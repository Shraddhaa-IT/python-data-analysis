# Australian ICT Jobs Analysis

## Project Overview
This project explores Australian ICT occupation data using Python to identify employment patterns, weekly earnings, and employment growth across different ICT roles.

The analysis focuses on comparing ICT occupations and presenting key findings through data visualisation.

## Objectives
- Explore employment levels across Australian ICT occupations
- Compare median weekly earnings between ICT occupation groups
- Examine annual employment growth
- Identify ICT occupations with high employment
- Visualise relationships between employment and earnings

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Analysis

The project includes:

- Data loading and inspection
- Data cleaning and preparation
- Filtering Australian ICT occupations
- Employment analysis
- Median weekly earnings analysis
- Employment growth analysis
- Data visualisation using bar charts and scatter plots

## Key Findings

- Software Engineers had the highest employment among the detailed ICT occupations analysed.
- Software and Applications Programmers represented the largest employed ICT occupation group.
- Telecommunications Engineering Professionals had the highest median weekly earnings among the ICT occupation groups analysed.
- Employment levels varied substantially across ICT occupations.
- Visualisation helped compare employment and earnings across different ICT fields.

## Visualisations

The analysis includes visualisations of:

- Top ICT occupations by employment
- Median weekly earnings across ICT occupation groups
- Employment versus median weekly earnings

## Project File

`Australian_ICT_Jobs_Analysis.ipynb`

The notebook contains the complete Python analysis, data processing, results, and visualisations.
